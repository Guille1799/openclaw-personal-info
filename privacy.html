Política de
privacidad

Esta política describe la integración personal de OpenClaw con Gmail y Google Calendar. Su operador y titular de las cuentas es el propietario de este repositorio.

Datos y finalidad

Tras el consentimiento en Google, la aplicación puede acceder a los mensajes y sus metadatos, borradores y datos de los calendarios autorizados. Utiliza los datos necesarios para responder a consultas, preparar o enviar correo y gestionar las citas que pida el titular. Los permisos de Calendar pueden permitir gestionar calendarios y eventos; las operaciones se limitan al encargo del titular.

El acceso concedido no implica revisar continuamente todo el buzón ni crear tareas o eventos a partir de cada mensaje. Una petición del titular determina qué información se consulta y qué acción se realiza.

Almacenamiento

Los tokens OAuth y la configuración se guardan localmente mediante las herramientas de autenticación del equipo. No se publican en esta web ni en el repositorio. Los datos originales permanecen en los servicios de Google; los resultados consultados o generados pueden quedar en las conversaciones, registros y copias locales del asistente.

El titular controla la conservación de esos registros y puede eliminarlos desde su entorno. Revocar OAuth detiene el acceso futuro, pero no borra automáticamente los correos o eventos de Google ni las copias locales ya conservadas.

Procesamiento y terceros

El contenido pertinente de una consulta puede transmitirse al proveedor del modelo configurado para ejecutar la función solicitada. Ese procesamiento se rige también por las condiciones y opciones de privacidad del proveedor. Las credenciales OAuth no se incluyen deliberadamente en las solicitudes al modelo.

Esta integración no vende los datos de Google, no los usa para publicidad ni para entrenar modelos propios. Su uso y transferencia de información recibida de las API de Google se limita a estas funciones y debe cumplir la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado. Los mensajes enviados y las invitaciones de calendario pueden revelar información a los destinatarios indicados por el titular.

La web pública

Estas páginas son documentos estáticos en GitHub Pages. No contienen formularios de acceso, analítica añadida, publicidad, fuentes remotas ni scripts. GitHub puede procesar datos técnicos de las visitas, como la dirección IP, conforme a su política de privacidad. Las directivas para no indexar son una petición a los buscadores, no un control de acceso.

Retirada y contacto

Puedes retirar los permisos desde las conexiones de tu cuenta Google. Para consultas sobre la aplicación, usa el canal del repositorio sin adjuntar datos privados. No existe registro público de usuarios.

Cambios

Esta política se actualizará cuando cambien las funciones o el tratamiento de datos. Un uso nuevo que requiera permisos adicionales solicitará un nuevo consentimiento.
