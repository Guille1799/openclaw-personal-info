Un asistente privado para consultar correo y organizar tareas y citas, a petición de su titular.

Esta web explica la aplicación. No permite iniciar sesión, conectar una cuenta ni acceder al asistente.

Qué hace

OpenClaw personal es una configuración de uso personal de OpenClaw. La integración autorizada con Gmail permite buscar y leer correo, preparar borradores y enviar los mensajes que solicite el titular. La integración con Google Calendar permite consultar calendarios y crear o modificar las citas que se acuerden.

Las tareas y entradas de calendario se crean a petición. La conexión no activa respuestas automáticas ni publica correo, citas o conversaciones.

Cómo se conecta

El titular autoriza su cuenta directamente en Google mediante OAuth. Las credenciales se conservan en su equipo y no se incluyen en esta web ni en su repositorio. El contenido pertinente de una solicitud puede ser procesado por el proveedor del modelo configurado para atenderla.

Cómo retirar el acceso

En tu cuenta de Google, abre Conexiones con aplicaciones y servicios de terceros, selecciona la aplicación y retira el acceso. La aplicación dejará de poder consultar la cuenta hasta que vuelvas a autorizarla.

Sobre esta página

La aplicación es de uso personal y no ofrece registros públicos. Esta página no es un servicio oficial de Google ni una web oficial del proyecto OpenClaw.

Para consultas sobre esta integración puedes usar el canal del repositorio. Ese canal es público: no incluyas mensajes, citas, tokens ni otros datos privados.
